# Module D — Developing Alternatives (An Overview of Structured Decision Making, USGS & USFWS/NCTC, 2011)

## Source structure and scope
Training workbook module "Developing Alternatives", An Overview of Structured Decision Making, 2011,
USGS & USFWS National Conservation Training Center. Module developers: Angela Matz (USFWS), Mitch Eaton
(USGS), Paul Barrett (USFWS), Sarah J. Converse (USGS). Strategy-table section marked "Adapted from: Robin
Gregory, Compass Resource Management, Vancouver, BC." 7 pages; read in full. Prescriptive teaching
material; no empirical evaluation reported.

## Anchored details
- **p.1 (pitfalls):** "We have a natural human tendency to focus first on alternatives when making
  decisions rather than focusing first on objectives." Risks: "We tend to limit ourselves to a smaller set
  of alternatives"; "We may anchor on the first suggested alternative." Alternatives are "created after you
  decide where you'd like to go (with your objectives)."
- **p.2 (qualities):** "Distinctiveness – Outcomes of alternatives should be discrete from each other to
  limit an often infinite number of possible alternatives and to aid learning about which alternative is
  best"; iteration; seek input from other disciplines.
- **p.2 (six approaches):** "1. Focus on fundamental objectives 2. Address conflicting objectives 3.
  Challenge constraints 4. Visualize – use diagrams 5. Create groups of alternatives – portfolios &
  strategies 6. Revisit objectives." Under 1: "Work independently, then as a group." Under 2: imagine
  the best possible consequence for each objective and create one alternative to get there, then hybrids.
- **p.3 (challenge constraints):** "Identify both real & perceived constraints"; "Don't anchor on initial
  set of options"; "Develop alternatives before assessing feasibility & efficacy"; "Expand options:
  scope, scale, rearrange, combine."
- **p.4 (portfolios):** "A portfolio is a combination of like elements arranged in a set"; constraints
  are often used to limit the number of portfolios.
- **p.6 (strategy tables):** "Alternatives combining multiple unlike elements: Strategy Tables. List
  management options under each element. Select a coherent set among those to be one Strategy." Worked
  example (endangered species recovery): element columns Habitat Protection / Predator Control /
  Enhance Population / Monitor, each with option levels; named strategies ("Maintain Existing Population",
  "On the Go" (Dispersal), "Increase Population to Carrying Capacity") each pick one option per column.
  Second route: strategies "Based on alternative hypotheses about limiting factors," using influence
  diagrams.
- **p.7:** "The first list of alternatives is usually unnecessarily narrow"; "Create first, evaluate
  later"; good alternatives "Address all objectives."
