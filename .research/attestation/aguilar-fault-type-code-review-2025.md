# Exploring the Influence of Fault Type, Fault Position and Gender on the Testing Process using Code Review Technique

## Source structure and scope
Raúl A. Aguilar, Julio C. Diaz, Antonio A. Aguileta, Omar S. Gómez, Brenda L. Flores. *Computación y
Sistemas* Vol 29, No 4 (2025), per the journal article page. Controlled experiment with 54 students at a
Mexican institution reviewing code with seeded faults. Engagement depth: **abstract only** (journal page);
fault counts, effect sizes and statistical tests not read.

## Anchored details (abstract)
- "This study reports a controlled experiment, in which four exploratory analyses are developed, considering the
  factors: fault type, fault position and gender of the reviewer."
- "The experiment was developed in an academic setting with 54 students from a Mexican institution."
- "types of faults influence the detection process, since the tester detects more faults by commission than by
  omission, but also detects more computational faults compared to interface, data and cosmetic."
- "faults in the first half of the code are more visible than those in the second half."
- "regarding tester gender, no significant differences were observed in case of effectiveness."
