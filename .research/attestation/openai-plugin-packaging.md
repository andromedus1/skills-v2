# Package your plugin

## Anchored summary

“Create a plugin manually” directs authors to use a stable plugin name and states:
“Plugin hosts use it as the plugin identifier and component namespace.”

“Plugin structure” describes root `plugin.json` and a supported
`.codex-plugin/plugin.json` compatibility fallback. “Build your own curated plugin
list” describes marketplace entries for individual plugins. “Add an onboarding
skill” describes an optional packaged setup skill. These sections do not establish
automatic companion-plugin installation parity with Claude's bundle mechanism.
