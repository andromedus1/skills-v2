Upstream agile-workflow uses `.work/active/<kind>s/<id>.md` as path shorthand
(`scope/SKILL.md:438,448`, `release-deploy/SKILL.md:595,604`,
`review/references/substrate-side-effects.md:62,153,177,185`). Taken literally it
yields `storys` for stories; `substrate-side-effects.md:153` is the same archive
recovery template fixed in doc-review by `story-fix-doc-review-archive-path`.
Upstream-owned; a fork patch or upstream note would need a decision.
