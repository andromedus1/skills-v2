# Version-anchor conformance brief

Exercises the version-number anchor rule (CATALOGS §3 item 2): a version token
fires unless an in-corpus anchor carries it. On a cited line, the anchor is a
resolved or reduced-substrate attestation whose body contains the same token.

## Anchored — version-number must NOT fire

Lattice 2.4.0 adds streaming responses. [version-anchor-src]{1}
Lattice requires Python 3.12 or later. [version-anchor-src]{1}
The Lattice wire protocol is version 3. [version-anchor-src]{1}
Orbit 5.1 introduced tiered storage. [version-anchor-reduced-src]{2}
Orbit 5.1 and Lattice 2.4.0 were compared head to head. [version-anchor-reduced-src]{2} [version-anchor-src]{1}
